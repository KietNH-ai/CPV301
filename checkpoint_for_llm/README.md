# LLM Checkpoint Directory

This directory stores state checkpoints generated by LLM / AI agents during sessions.

## Checkpoint Policy
- When remaining context window tokens drop below 20% (or before running out of tokens), a checkpoint markdown file must be generated and saved here.
- Checkpoint naming format: `checkpoint_YYYYMMDD_HHMMSS.md` or `checkpoint_<step_name>.md`.
- Each checkpoint captures current progress, modified files, key findings, and next steps to ensure seamless continuation.
